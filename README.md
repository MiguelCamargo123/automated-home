# 🏠 Smart Home Simulator

A terminal-based Python application that simulates a smart home using Object-Oriented Programming (OOP).

The project allows users to interact with a virtual house by controlling lights and windows while simulating temperature changes and the passage of time.

---

## ✨ Features

- 💡 Turn lights on and off
- 🪟 Open and close windows
- 🌡️ Dynamic temperature simulation
- 🕒 Automatic time progression
- 📋 Display the current house status
- 🖥️ Interactive terminal menu
- 🌍 Cross-platform terminal support (Windows, Linux, and macOS)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/smart-home-simulator.git
```

### Enter the project directory

```bash
cd Smart-Home-Simulator
```

### Run the application

```bash
python main.py
```
